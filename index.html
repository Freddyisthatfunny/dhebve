Play Windows games on your iPad

  1. Add a game — a .zip of its folder, or the .exe together with its files.
  2. Download Windows once (about 170 MB) using the banner above, so games start faster.
  3. Tap the game to play. Tap ✎ in the game to move or change the buttons.

Works with 32‑bit Windows games, roughly from the Windows 95 – XP era.
